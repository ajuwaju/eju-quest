# Neon Pass

A cyberpunk study game for the EJU science track: Mathematics Course 2, Physics and Chemistry, aimed at English-taught programs such as the University of Aizu's ICT Global and Kyushu University's IUP in Electrical Engineering and Computer Science.

## What's inside

- **Subject tabs:** Math, Physics and Chemistry, each split into lessons (29 in total). Every lesson teaches first (notes, worked example, traps, exam tip) and then quizzes on that lesson only. 70% passes it.
- **280 original questions** with an "I don't know" button and step-by-step explanations.
- **Checklist:** EJU application steps, English test, Aizu and Kyushu application steps, practice goals, every lesson (ticked automatically on a pass) and your own items.
- **Universities:** detailed write-ups of English-taught programs that take EJU Math Course 2 plus physics or chemistry, with a form to add more.
- **Shards:** spaced-repetition flashcards for math, physics and chemistry formulas.
- **Corp exam:** a timed 20-question mock across all three subjects.
- **Intel and Resources:** 2027 exam dates, scoring, averages, the 2026 syllabus, strategy, and links to every official JASSO math and science past paper.
- **Game layer:** XP, levels, daily goal and uptime streak, daily gigs, creds, cyberware, achievements, an original crew with a story, and Allanah on comms.

The background is a single still image, so the site stays light on phones and older laptops.

Progress is saved in the browser. Use Runner, Save file to back it up or move devices.

## Personalise it

Edit `assets/config.js` to change the encrypted message that unlocks at level 2.

## Run locally

Any static server works, for example `python3 -m http.server`, then open http://localhost:8000.
